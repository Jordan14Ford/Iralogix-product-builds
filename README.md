# Onboarding

The identity step that starts account onboarding. This screen matches the Figma frame **Verify Account**: a progress header, the identity form, and the workspace overview.

## Run locally

```bash
npm install
npm run dev -- --hostname 0.0.0.0 --port 43123
```

Open [http://127.0.0.1:43123](http://127.0.0.1:43123) for the identity step. After that form is complete, Get Started opens [http://127.0.0.1:43123/create-login](http://127.0.0.1:43123/create-login).
